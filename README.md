# Play-Pal ontvanger

De eigen Google Cast-ontvanger van Play-Pal, een muziekspeler voor Windows die met NVDA te bedienen is.
Deze pagina wordt door een Google-speaker geladen terwijl Play-Pal ernaar cast. Hij speelt dezelfde
stroom als de standaardontvanger van Google, en geeft "Hey Google, volgende" en "vorige" door aan
Play-Pal op de pc (namespace `urn:x-cast:nl.playpal.bediening`).

Gehost via GitHub Pages: https://termisdemaster.github.io/playpal-ontvanger/
Bevat geen geheimen. De rest van Play-Pal staat in een privérepository.
